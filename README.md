# bubble_pop_surprise_duck

The collaborative bubble popping game in which one may meet a duck (surprisingly)

## Play

Open `index.html` in a browser (or serve the folder with any static file
server / GitHub Pages) and start popping bubbles.

- Bubbles float up from the bottom of the screen — click or tap to pop them.
- It's collaborative: play solo, or share one screen/device with friends and
  pop together toward the same score.
- Every pop fills the shared **Duck-o-Meter**. Once it's full, the next pop
  reveals a **Surprise Duck** for a big bonus. Ducks can also appear at
  random even before the meter is full, so keep your eyes open.
- Watch out — every so often a bubble turns out to be just a goose, not a
  duck!

No build step or dependencies are required; it's a static HTML/CSS/JS page.
